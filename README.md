BK톡톡 · BK쇼츠의 가족 앱이에요. 주소: https://bangkeukryul.github.io/bk-studio/

| 탭 | 내용 |
|---|---|
| 📝 대본 | 소재 7가지 · 분량 15~60초 · AI 요청서(Gemini · ChatGPT · Claude) · 답 정리 · 자동 검사 |
| 🎙 목소리 | 💻 내 PC 목소리(BK보이스 · GPT-SoVITS) · 🎧 음성 파일 · 🎤 문장별 녹음 · 🧬 내 목소리 등록 |
| 🎬 장면 | 사진 · 캡처 · 영상 · 주제 배경 자동 · AI 영상 장면(Flow · Grok · Kling 프롬프트) · 🗣 립싱크 아바타 |
| 🎨 꾸미기 | 자막 스타일 5가지 · 채널 띠 · 출처 · 장면 전환 · 기본 음악 |
| 📤 만들기 | 1080p/720p MP4 · 공유 · 유튜브 제목 · 설명 · 해시태그 |
